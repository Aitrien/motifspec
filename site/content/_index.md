A prototype comes together fastest when its decisions are already made. MotifSpec makes them once, so each new project starts from them instead of from a blank stylesheet.

### Decisions made once

One set of tokens for colour, type, space and motion, components with the markup to copy, and layouts for a portfolio, documentation or a dashboard. Choose the layout, take its components, and the first screen already looks finished.

### Written for people and AI assistants

Every rule says when to use something and when not to, in the same words for a person reading these pages and for an assistant reading them through the MCP server. Both build from the same components and tokens.

### Checked every time

The checker holds each project to the release it pins, and the system is validated on every change: contrast in both themes, naming, and the docs against the code. A raw colour or an invented class is caught before it ships.

### One change reaches every project

A fix or a new component is made here once, and each project gets it when it moves to the next version, so prototypes that use MotifSpec stay consistent with each other as they grow.
