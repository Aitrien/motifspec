Principles #

The same seven lines open the README, which is the first thing an AI assistant reads.

  • Name the role, not the page.Tokens and components describe the job they do, so a recipe app, a docs site and this portfolio can share them.
  • Colour and type carry meaning.Hue marks a link, a status or focus. Ornaments are decoration, always hidden from assistive tech.
  • Measure it, don't eyeball it.Reading text meets 7:1, controls and focus meet 3:1, and every pair is checked in both themes on every build.
  • HTML first, script second.Content, navigation and code work without JavaScript. Scripts add the theme toggle, copy buttons and TOC tracking.
  • Square, hairline, labelled.Structure is drawn with 1px rules, square corners and mono labels, like a field ledger. Buttons, nav items and icon-only controls are the one exception: they are pills, so anything you can press is recognisable at a glance.
  • Motion confirms a change.Only state changes animate, plus the pausable drift of the contour survey behind the page; text never moves, and reduced motion means none.
  • One accent, one ornament.Sap green marks action. Yarndings and the contour survey (the backdrop, or the specimen plate) are the only decoration, once per view.

Foundations #

Five dye-plant hues, three typefaces and a 4px grid. Primitives hold raw values; everything you build with is a semantic token that points at them, and dark mode re-points the same names.

Primitive palette primitive.color.*

Generated in OKLCH so steps are perceptually even, stored as sRGB. Primitives are never used directly in components.

{{PALETTE}}

Semantic roles color.*

Each role names its light and dark primitive. The page switches with light-dark(), following your system unless you pick a theme.

{{SEMANTIC}}

Contrast pairs codex.pairsWith

Every pair declared in the tokens, measured in both themes at build time. Reading text targets 7:1 (AAA); metadata and status labels 4.5:1; controls, focus and graphics 3:1. The lowest body-text ratio is {{WORST_BODY}}:1.

Typefaces font.family.*

Three OFL families, {{FONT_KB}} KB in total as Latin-subset WOFF2. National Park comes from US national-park trail signage; it carries display, body and UI. JetBrains Mono carries code and every label.

Motion motion.*

Hover or focus a track to run it. With reduced motion turned on in your system, every duration below becomes 0ms.

duration.fast | easing.standard

120ms. Hover colour, borders, the button arrow.

duration.base | easing.standard

200ms. Disclosures and the TOC marker.

duration.slow | easing.enter

320ms. Rare one-off confirmations.

duration.plate | easing.enter

1600ms. Each contour's draw-in, once, on load.

duration.drift | linear

60000ms for the contour terrain to drift one noise unit, behind the frost or on the plate. The only loop; always pausable, and still under reduced motion.

Never moves: text, headings, layout, page transitions, scroll-triggered reveals. Theme changes and focus rings are instant. The contour drift is the one loop: it has a pause control and stops under reduced motion.

A token without a rule is a colour with a name. An assistant can't tell color.accent on a button from color.accent on a full-page background, so the description becomes the contract.

Why tokens need rules #

Every semantic token carries a usage rule in its $description. The MCP server returns it with the value, and the assistant follows it like a lint message.

  • Name the role, never the page.
  • State when not to use it, not only when to.
  • Keep it to one or two sentences.

The pairs contract #

Text tokens list the surfaces they may sit on. Press Ctrl + K in the dashboard to search pairs, or query the server directly.

Things that are easy to build are also reliable.

Jensen Huang | Jensen Huang gets mobbed by engineers in Taiwan, Lex Fridman

Failure modes

  1. A pair is declared but one theme fails: CI blocks the release.
  2. A component uses a primitive directly: the validator flags it.
