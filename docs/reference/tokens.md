# Tokens

Every semantic token, with its value and rule. Pages and components use these; the primitives behind them are not for use outside MotifSpec.

*Generated from `tokens/`: deprecated tokens.*

A token's CSS name is `--cx-` and its name with dashes: `color.text.primary` is `--cx-color-text-primary`. A colour shows its light value, then its dark one.
